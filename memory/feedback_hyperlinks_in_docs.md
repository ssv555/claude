---
name: feedback_hyperlinks_in_docs
description: All external service mentions in docs must be hyperlinks, not plain text
type: feedback
---

Любое упоминание внешнего сервиса в документации должно быть гиперссылкой на этот сервис, а не просто текстом.

**Why:** Пользователь считает plain-text ссылки на сервисы «рукожопным подходом» — документация должна быть навигируемой.

**How to apply:** Во ВСЕХ проектах и документациях — если упоминается сервис (SMS.ru, Twilio, Yandex 360 и т.д.), писать `[SMS.ru](https://sms.ru/)`, а не просто `SMS.ru`. Это касается не только таблиц, но и любых текстовых упоминаний.
