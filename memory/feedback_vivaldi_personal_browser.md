**Что это:** глобальный MCP-сервер `playwright_vivaldi`, цепляется через CDP к живому Vivaldi пользователя. Профиль `D:\Data\Tools\Vivaldi\ssv555@yandex.ru` содержит ВСЕ авторизации админок, личной почты, банкинга, DNS-панелей и т.д.

**ДЕФОЛТ ДЛЯ BROWSER-АВТОМАТИЗАЦИИ — ВСЕГДА Google Chrome (`mcp__Claude_in_Chrome__*`).** Vivaldi разрешён ТОЛЬКО для конкретного проекта, где пользователь это явно разрешил, — НЕ глобально. Инцидент 2026-06-12: Claude применил Vivaldi вне того проекта и перезапустил закрытый браузер — пользователь жёстко запретил.

**Когда запускать Vivaldi:** только по явной команде «запускай Vivaldi» / «через Vivaldi» / «делай в живом браузере» в рамках разрешённого проекта. Команда: `"C:\Program Files\Vivaldi\Application\vivaldi.exe" --user-data-dir="D:\Data\Tools\Vivaldi\ssv555@yandex.ru" --remote-debugging-port=9222` через `Bash` с `run_in_background: true`.

**Правила использования (нерушимые):**
1. **Per-task разрешение.** Использовать MCP-тулы `mcp__playwright_vivaldi__*` ТОЛЬКО с явным «да, через Vivaldi» на каждый случай. Никогда автономно, ни на чтение, ни на запись.
2. **Не закрывать НИЧЕГО — и не ПРЕДЛАГАТЬ закрывать.** Запрещено: `browser_close`, `browser_tabs` с `action: close`, любое закрытие окна/вкладки. ОДИНАКОВО запрещено даже ПРЕДЛАГАТЬ пользователю закрыть его вкладки/окна — это его пространство, не моя зона комментариев. Если MCP тормозит из-за 93 вкладок — это моя проблема, я ищу обход (одноразовый Playwright-скрипт, изолированный браузер, отказ от задачи), а не прошу его подчищать рабочее место. Закрывает ТОЛЬКО сам пользователь и ТОЛЬКО по своему решению.
3. **Не трогать закладки.** Никаких добавлений/удалений/перемещений в bookmarks.
4. **Чужие вкладки — НЕ ТРОГАТЬ.** Работаю ТОЛЬКО в вкладках которые сам открыл (`browser_tabs action=new` или `curl /json/new`). Существующие вкладки пользователя: НЕ активирую (`Target.activateTarget`), НЕ переключаюсь (`browser_tabs action=select`), НЕ навигирую в них, НЕ читаю их содержимое (`browser_snapshot` пока активна чужая вкладка). Даже если в чужой вкладке открыт сервис который мне нужен (webmail, админка) — открываю свою новую вкладку на том же URL, cookies подцепятся автоматически из общего профиля. Поиск нужной вкладки «по имени через CDP» — НЕ оправдание для активации, это всё равно «трогать».
5. **Минимизировать побочные эффекты.** История, autofill, скачки — старайся не плодить мусор.

**Регулярный playwright (Chromium, профиль `claude-def`) и `playwright_iso` — без этих ограничений**, это мои собственные браузеры для проектной работы. Ограничения касаются только `playwright_vivaldi`.

**Why:** 2026-05-12 — пользователь предложил подключить личный Vivaldi-профиль чтобы не скакать по браузерам при админских задачах (DNS, webmail, банкинг и т.д.). Профиль содержит чувствительные авторизации — поэтому жёсткий per-use контроль и запрет на закрытия, чтобы случайно не убить рабочие вкладки.
