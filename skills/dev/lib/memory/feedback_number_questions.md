When presenting multiple questions, open items, or options to the user — ALWAYS number them (1., 2., 3.).

**Why:** User needs to reference items by number in his reply ("ответ на 2", "по 1 скажу так"). Unnumbered bullets force him to quote text. He has flagged this as a recurring violation.

**How to apply:**
- Open questions at the end of a plan / report → numbered list.
- Multiple clarifying questions in one message → numbered.
- Options / variants offered to user → numbered.
- Even single-question blocks in a broader message — number it (`1.`) if siblings exist.
- Applies to ALL output: plain text, sections in plan files, ExitPlanMode summaries.
