Когда пользователь присылает скриншот с красным прямоугольником, стрелкой или любой другой явной визуальной меткой — это ПРИКАЗ «почини это», а не вопрос «что ты об этом думаешь?». Исправлять в том же turn'е, без обсуждения вариантов, без спроса «делать?», без объяснений почему оно так получилось.

**Why:** В сессии 2026-04-23 пользователь 3 раза присылал скриншоты с красным выделением пустого пространства слева от сайдбара. Я каждый раз вместо рефактора объяснял «это существующий `max-w-[1600px]`, не моё», предлагал варианты на выбор, спрашивал какой делать. Потратили много токенов и времени впустую. Пользователь явно сказал: «красный прямоугольник = приказ».

**How to apply:** Любое изображение с красной геометрической разметкой от пользователя → немедленно определить что отмечено → применить исправление → подтвердить через Playwright-скрин → коротко доложить. Объяснение причин бага — ПОСЛЕ фикса и только если реально нужно для понимания. Если для фикса нужен рефактор структуры — делать рефактор, не точечный патч. Не спрашивать «делать?» — ответ уже получен в виде красной пометки.
