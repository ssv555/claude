---
name: feedback_task_format
description: When listing tasks/priorities, always show the source file link BEFORE the task description
type: feedback
---

When presenting task lists or priorities, always write the source file (as a clickable link) first, then the task description. Don't mix — some with file, some without.

**Why:** User got confused when some tasks had file references and some didn't — inconsistent format.

**How to apply:** Every task item starts with `[filename.md](path) — description`. No exceptions.
