---
name: TODO section always last in document
description: In any document containing a TODO section alongside other content (session archives, docs, plans, README), the TODO section must be the final section of the file
type: feedback
---

В любом документе, содержащем раздел TODO вместе с другим контентом (архивы сессий, docs, планы, README и т.п.), раздел TODO должен быть **самым последним** в файле.

**Why:** Чтобы можно было открыть файл, сразу прыгнуть в конец (End / Ctrl+End) и увидеть что недоделано, без поиска по всему документу. Пользователь регулярно возвращается к TODO-спискам — они должны быть в предсказуемом, фиксированном месте.

**How to apply:** При создании или редактировании любого markdown-файла, где есть блок "TODO" / "Оставшиеся задачи" / "Что доделать" — убедиться что этот блок идёт **в конце файла**, после всех остальных разделов (Выполнено, Модифицированные файлы, Примечания и т.д.). Применимо к session-archive, плановым документам, отчётам, любой структурированной документации.
